What's New in KHub v2.6
KHub v2.6 introduces a new Multi-Engine All-File Wireless GitHub Updater (installing index.html, config.xml, khub.sh, kindlestore.json, and all assets with disk verification and hot-swap activation), adds Battery Health & Process Power Tracking with 5m/15m/30m adaptive heartbeats, renames RSS News to RSS Feed (with 5x text zoom scaling) and adds Add Feeds on Phone/PC inside the RSS Feed settings panel so you can manage both your Gemini API Key and custom RSS feeds at http://<Kindle-IP>:8088. We also upgraded device telemetry to use the live Cloudflare Worker backend and fixed the in-app OTA System Updater so updates write cleanly to disk and reload without looping.
